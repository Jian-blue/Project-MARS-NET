# Public Repository Checklist

Before switching the GitHub repository to public visibility:

- [ ] Add the final `network/MARS-NET.pkt` file.
- [ ] Confirm the `.pkt` opens successfully in the intended Packet Tracer version.
- [ ] Remove any hidden or temporary files from the repository.
- [ ] Check the Packet Tracer file for passwords, credentials, or test secrets that should not be public.
- [ ] Decide whether publishing the original academic report is appropriate; it contains student names/IDs and institutional information.
- [ ] Confirm your university/course does not prohibit public posting of the submission.
- [ ] Replace the contribution template with the real individual task split, if one exists.
- [ ] Check that screenshots do not expose unrelated personal information.
- [ ] Keep `README.md` focused on architecture, capabilities, validation, and how to reproduce the demo.
