# Packet Tracer Network Artifact

The primary simulation artifact for this project is the Cisco Packet Tracer `.pkt` file.

Expected repository path:

```text
network/MARS-NET.pkt
```

The `.pkt` file is the source of truth for the actual device state. The configuration snippets in `/configs` are human-readable reference material extracted from the submitted lab report; they are not a replacement for the Packet Tracer artifact.
